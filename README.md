# Hi, I'm Nataniel

Founder of **[Privera](https://privera.se)**, a Windows app that finds and removes personal data from PDF and Word files – entirely on your own computer. I'm studying industrial engineering (civilingenjör, industriell ekonomi) at Mid Sweden University.

### What I build

- **[Privera](https://privera.se)** – local redaction for Swedish documents. OCR for scanned files, text removed from the file instead of covered, and an audit log for every export. The source is private; the product is at privera.se.
- **[Rosetta](https://github.com/Nataniel0212/rosetta-eclab)** – names the columns in BioLogic EC-Lab (.mpr) battery files that parsers don't recognise, using physics instead of a language model. 522 of 586 columns right on 7 public datasets it had never seen. On PyPI.
- **[Turncoat](https://github.com/Nataniel0212/turncoat)** – measures how often tool-using AI agents get hijacked by prompt injection, with confidence intervals. Built for the Nebius × NVIDIA Global AI Hackathon. [Live demo](https://turncoat-redteam.vercel.app)
- **[File Converter](https://github.com/Nataniel0212/calculator-file-converter)** – Casio and TI calculator files to text and back, byte-exact, in the browser. [Open it](https://nataniel0212.github.io/calculator-file-converter/)
